## ⭐ Featured projects

### 📈 [Demand Forecasting & Replenishment Platform](https://github.com/SpiritGitHub/demand-forecasting-platform)

**Python · PyTorch · XGBoost · LightGBM · Prophet · FastAPI · Streamlit · MLflow · Airflow · PostgreSQL**

An end-to-end data science platform that forecasts product demand across stores for **7, 14, and 30-day horizons** and transforms predictions into inventory decisions.

- Compares seven forecasting approaches, from Seasonal Naive to LSTM
- Uses walk-forward temporal backtesting with MAE, RMSE, WAPE, and forecast bias
- Enriches data with weather, holidays, calendar, promotion, and store features
- Generates safety stock, reorder points, order quantities, and stockout-risk alerts
- Connects experimentation, model registry, API delivery, dashboarding, and orchestration

### 🗣️ [STS Ewe ↔ Français](https://github.com/SpiritGitHub/STS_ewe_fr)

**Python · FastAPI · Whisper · NLLB · ASR · Machine Translation · TTS**

An end-to-end speech-to-speech translation system supporting **Ewe → French** and **French → Ewe**.

- Provider-based backend architecture with a mock mode for fast demonstrations
- Speech-to-text, translation, text-to-speech, and speech-to-speech entry points
- Dataset manifests, training workflows, inference modules, and evaluation tooling
- Designed as a foundation for practical language technology in under-resourced languages

### 🇹🇬 [TogoQA](https://github.com/SpiritGitHub/TogoQA)

**React · Vite · Tailwind · FastAPI · PostgreSQL · pgvector · Celery · Redis · Docker**

A trustworthy question-answering system for educational data from Togo, designed around evidence rather than unsupported generation.

- Hybrid full-text and vector retrieval with reranking
- Verifiable answers with official sources, pages, and passages
- Confidence calibration and explicit refusal when evidence is insufficient
- Claim decomposition, verification, and support for structured educational data

### 🔎 [Matplotlib RAG](https://github.com/SpiritGitHub/MatplotlibRag)

**Python · Sentence Transformers · BM25 · Chroma · Ollama · Streamlit**

A local RAG assistant that answers natural-language questions using the official Matplotlib documentation without relying on web search at query time.

- Markdown ingestion and document chunking
- Local embeddings and vector search
- Hybrid BM25 + semantic retrieval
- Source display and a simple Streamlit interface

### 🎙️ [Ewe ↔ Français Voice Translation](https://github.com/SpiritGitHub/trad_ewe_fr)

**Python · Flask · Whisper · NLLB-200 · gTTS · SQLite**

A web application combining speech recognition, neural translation, text-to-speech, translation history, and evaluation metrics such as **WER, BLEU, and chrF**.

## 🧭 Engineering principles

- **Data before assumptions:** validate the source, understand the bias, and document the limits.
- **Evaluation before claims:** compare baselines, use appropriate metrics, and validate over time.
- **Reliability by design:** expose uncertainty, verify outputs, and abstain when evidence is insufficient.
- **Research that ships:** connect experiments to APIs, interfaces, documentation, and real use cases.
- **Simplicity where possible:** build modular systems that are easy to understand, test, and evolve.
